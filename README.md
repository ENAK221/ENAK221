## Bonjour 👋

Je suis **Ousmane KANE**, développeur full-stack. Je construis des applications web où le design, l’expérience utilisateur, la performance et la qualité du code avancent ensemble.

Je peux intervenir sur l’ensemble d’un produit : de la conception de l’interface jusqu’à l’API, la base de données, l’authentification, les tests et la mise en production.

### Mon approche

- transformer un besoin en interface claire et responsive ;
- créer des composants réutilisables et accessibles ;
- développer des API structurées et sécurisées ;
- connecter proprement le front-end aux données ;
- tester, améliorer et maintenir le produit dans le temps.
